# planner-bot — Telegram-планировщик, который понимает по-русски

Личный планировщик в Telegram: задачу кидаешь обычным сообщением, бот сам
вытаскивает дедлайн из текста, напоминает о нём и утром присылает сводку дня.
Большие задачи ИИ-агент раскладывает на конкретные шаги.

Проект родился из собственной боли: задачи копились в заметках и в голове,
дедлайны пропускались, а крупные задачи висели неделями, потому что было
непонятно, с чего начать. Теперь этим занимается бот.

## Что умеет

- **Добавление задачи просто текстом:** «сдать тестовое завтра в 18» →
  задача + дедлайн 17.09 18:00
- **Распознавание дат без ИИ** (регулярки + парсер на Go):
  «сегодня / завтра / послезавтра», «в 19», «15.10 в 14:30», «3.01»,
  «через 2 дня / 30 минут / пару часов / полтора часа»
- **Напоминание** в момент дедлайна
- **Утренняя сводка** (окно 09:00–12:00): просрочено 🔴 / сегодня 🟡 / дальше 🔵
- `/plan большая задача` — ИИ-агент раскладывает её на 3–6 шагов
- `/day` — план на день + совет ИИ, с чего начать
- `/list`, `/done N`, `/del N` — список, закрыть, убрать

Без ключа ИИ бот полностью работает на правилах — ИИ только усиливает
(`/plan` и совет дня).

## Быстрый старт

```bash
# 1. Создай бота у @BotFather и получи токен
# 2. Запусти:
PLANNER_TOKEN=123456:ABC... go run .
# 3. Напиши боту в Telegram /start
```

Переменные окружения:

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `PLANNER_TOKEN` | токен бота от @BotFather (обязательна) | — |
| `PLANNER_API_KEY` | ключ OpenAI-совместимого API для ИИ-функций | нет (ИИ выключен) |
| `PLANNER_BASE_URL` | эндпоинт провайдера | `https://open.bigmodel.cn/api/paas/v4` (GLM) |
| `PLANNER_MODEL` | модель | `glm-4-flash` |
| `PLANNER_OWNER` | твой telegram id (тогда бот слушает только тебя) | нет |
| `PLANNER_DATA` | путь к файлу задач | `./tasks.json` |

Подходят любые OpenAI-совместимые провайдеры: GLM (по умолчанию),
OpenRouter (`https://openrouter.ai/api/v1`), Gemini
(`https://generativelanguage.googleapis.com/v1beta/openai`), локальный Ollama.

## Как устроено

- **Go 1.21+, только стандартная библиотека** — ноль внешних зависимостей
- Telegram Bot API через **long polling** (`net/http`, без SDK)
- хранилище — **JSON-файл с атомарной записью** (tmp + rename), переживает рестарт
- парсер дат — регулярки + **ручная проверка границ слов**: `\b` в Go-регулярках
  определён только для ASCII и не видит кириллицу, из-за этого «через» и «в»
  с `\b` вообще не находятся
- фоновый **планировщик-тикер**: напоминания и утренняя сводка
- ИИ — тонкий клиент `chat/completions`; ответы модели валидируются
  (JSON-массив шагов), при сбое бот деградирует на правила, а не падает
- тесты на парсер дат и хранилище: `go test ./...`

## Запуск как сервис (systemd user)

```bash
mkdir -p ~/.config/systemd/user ~/.config
cp deploy/planner-bot.env.example ~/.config/planner-bot.env  # заполни
cp deploy/planner-bot.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now planner-bot
journalctl --user -u planner-bot -f   # логи
```

## Ограничения и идеи

- один пользователь — это личный бот; таймзона берётся системная
- идеи дальше: подзадачи-чеклисты, повторяющиеся задачи («каждую пятницу»),
  перенос просроченного «на завтра» одной командой
